# Apex Build - Construction Company Website

A premium, state-of-the-art frontend website for **Apex Build**, a professional construction and architectural solutions company. Built entirely with clean semantic HTML5, modern vanilla CSS variables, and native JavaScript.

## 🚀 Live Demo & Description for GitHub "About"

> **GitHub About Description:**
> 🏗️ A premium, 100% responsive frontend website for a construction & architectural company. Built with HTML5, Vanilla CSS, and modern JavaScript. Features an animated SVG preloader, custom scroll-triggered counter animations, filterable portfolio grids, and zero horizontal scroll.

---

## ✨ Features

* **⚡ Custom Animated Preloader:** An interactive fullscreen preloader featuring a self-drawing SVG building outline and filling blocks. Runs smoothly for 2.5 seconds on load, then fades out to reveal the hero section.
* **📱 100% Responsive Grid Layout:** Fully optimized for all viewports including portrait mobile screens, tablets, laptops, and ultra-wide desktops.
* **🚫 Zero Horizontal Scrollbar:** Zero-scroll overflow-safe styling implemented across the entire layout using box-sizing rules, responsive percentages, and hidden parent bounds.
* **✨ Dynamic Visual Effects:** 
  * Glassmorphic sticky header that shrinks on scroll.
  * Intersection-Observer-powered scroll-triggered reveal animations.
  * Interactive counting statistics counters.
  * Hover lift-up card transitions, glow effects, and SVG icons.
* **🎨 Premium Styling System:** Curated Slate Dark and Amber Safety Orange color scheme designed for industrial engineering themes.
* **🔍 Filterable Portfolio:** Dynamic tag buttons allowing clients to sort project grids by Category (Commercial, Residential, Renovation) on-the-fly.
* **💬 Testimonial Slider:** Auto-playing slideshow showcasing client feedback and reviews.
* **📩 Interactive Contact Form:** Premium contact form with floating input labels, validation, and mockup success dialog response.

---

## 🛠️ Built With

* **HTML5** - Semantic layout structure.
* **Vanilla CSS3** - Variables, keyframes, transitions, flexbox, and grid layouts.
* **Vanilla JavaScript** - Sticky menus, sliders, count-up animation, filter grid logic, and Intersection Observer API.
